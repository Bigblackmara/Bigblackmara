### Faceless content, fully automated pipelines 🎬

I build **automation that runs a faceless video channel end-to-end** —
watching livestreams, clipping viral moments, branding clips with overlays,
and shipping them to Instagram Reels & YouTube Shorts on autopilot.

</div>
